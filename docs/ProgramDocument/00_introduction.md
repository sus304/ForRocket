# Introduction

ForRocket はロケットの飛行軌道シミュレータである。
軌道計算は並進 3 自由度・回転 3 自由度の計 6 自由度の運動方程式で記述している。
可能な限りロケットエンジンの種別に依存しないように記述しており、液体・固体・ハイブリッドロケットのいずれでも計算可能である。

軌道計算中には様々なフライトシーケンスイベントを任意のタイミングで発生させることができる。
エンジンのカットオフ、段間分離、デスピン、フェアリング分離、パラシュート開傘などがサポートされている。

ForRocket へのパラメータ入力は JSON 形式のテキストファイルと CSV 形式のファイル（推力履歴・空力係数など）の 2 種であり、容易に編集が可能である。
計算結果は CSV 形式で出力され、Excel やスクリプトによるポスト処理が可能である。

## 主な機能

- **6DoF フライトシミュレーション** — 並進・回転を統合した運動方程式を Dormand-Prince 法で数値積分
- **多段ロケット対応** — 最大 3 段まで連続して計算（段間分離イベントで接続）
- **パラシュート回収** — 時刻指定/頂点自動開傘・2 段開傘に対応
- **姿勢制御プログラム** — 角度モード（方位角・上下角・ロール角を時系列で指定）とレートモード（角速度を時系列で指定）の 2 種。軸ごとに制御の有効/無効を設定可能（例: ロール軸のみ制御、ピッチ・ヨーは空力自由）
- **ガスジェット（スピン安定用）** — ランチクリア後の指定時間だけロールモーメントを印加
- **デスピン制御** — 指定時刻でロール角速度を瞬時にゼロにする（ヨーヨーデスピナ想定）
- **風の影響** — 高度分布を CSV で指定可能

## 入出力の概要

入力はすべて JSON/CSV ファイルで与える。拡張ツール（Python スクリプト等）はこれらのファイルを生成・解析することでソルバと連携できる。

出力は `{Model ID}_stage{N}_flight_log.csv` という名前の CSV ファイルで、実行ディレクトリに生成される。デフォルトで 100 列以上の詳細データを含む（`-m` オプションで最小出力に切り替え可能）。

## バージョン

現在のバージョンは **v4.4.2**（2026年6月）。

### v4.2.0 以降の主な変更
- **v4.2.2**: 空力モーメントの基準長を機体全長から**機体直径**に変更。フィンカントロールモーメント係数 `Cld` を**クロスフィン合計値**として入力する仕様に変更（旧版の「1 枚あたり ×4」ではない）。
- **v4.3.x**: 横方向重心（y/z-C.G. Offset）入力・慣性乗積 CSV 入力を追加。スピン共振解析パラメータ（`ResonanceRatio` 等）を出力に追加。積分器の許容誤差を `Solver Tolerance Abs/Rel` で指定可能に。
- **v4.4.2**: 横方向重心を推進薬との質量重み付けで実効化。**ジェットダンピングモーメント**を追加（`Mx/My/Mz-jetdump` を出力）。
