# Model Limitations & Roadmap

ForRocket の物理モデル・数値計算の既知の制約と、高高度・長時間・軌道級の飛行へ
拡張する際に必要になる項目の整理。サブオービタルの通常運用では現状のモデルで
十分だが、適用範囲を広げる場合はここを確認すること。

## 現行モデルの適用範囲と既知の制約

| 領域 | 現行モデル | 制約・誤差の目安 |
|---|---|---|
| 重力 | `"Gravity Model"` で選択。`legacy`（既定）: GM/(a+h)² を鉛直下向き / `pointmass-j2`: 質点＋J2（地心半径・緯度依存） | legacy は緯度 45° で大きさ最大 ~0.35% 過小・方向誤差最大 0.19°。数百秒の飛行で km 級に積分される。長時間・高高度は pointmass-j2 を推奨 |
| 大気 | US Standard Atmosphere 1976（〜86 km 解析層、86〜1000 km 表引き） | 標準大気のみ。季節・緯度変動、大気擾乱モデルなし |
| 風 | 高度プロファイル CSV（東西・南北成分、線形補間） | プロファイル上端・下端の外側は**風速ゼロ**として扱う（zero-fill）。鉛直風なし。高高度まで飛ぶ場合はプロファイルを実プロファイルの上端まで与えること |
| ECI↔ECEF | 打上時刻基準の単純 z 軸回転（ω⊕t） | 歳差・章動・極運動なし。1 時間未満の飛行では位置誤差 ≪10 m で実用上問題ないが、J2000/GCRF 基準の軌道要素を出すには GMST エポック対応が必要 |
| 空力（法線力） | 線形化 Fy=Fn·β, Fz=−Fn·α | α³/6 の相対誤差（10° で 0.5%、15° で 1.1%）。大迎角では線形 CNa 自体が主要な制約 |
| 空力係数テーブル | マッハ数 1 変数の線形補間 | 迎角依存（2 変数）テーブルは未実装（`Interp2d` スタブ）。スプライン補間は実装済みだが未接続 |
| 積分器 | dopri5 適応ステップ、既定許容誤差 1e-6 | ECI 位置換算で数 m 程度の許容。姿勢精密評価・長距離では Rel 1e-7〜1e-9 推奨（[02_input_style.md](02_input_style.md) 参照） |
| 推進剤質量 | RHS にクランプなし | 燃焼終了ステップで最大 ~1e-7 kg 程度ゼロを下回ることがある（実用上無害） |
| 姿勢プログラム（角度モード） | 制御軸の出力オイラー角をプログラム値で上書き | 内部クォータニオン状態には書き戻さないため、制御終了時に出力姿勢がドリフト済みの内部状態へ不連続にスナップする（例: 60 s 保持で ~0.8°）。E2E テストで特性化済み |

## 軌道級飛行への拡張時に必要な項目（未実装）

実装順の目安として列挙する。いずれも汎用シミュレータとしての拡張項目。

1. **ケプラー軌道での検証**: 大気なし・質点重力で二体問題の解析解と 1 周期比較する
   V&V テスト。ECI 積分・座標変換・ソルバ精度の一括検証になる
2. **保存量監視**: 無推力・無抵抗区間での比軌道エネルギー・角運動量保存のテスト
3. **J2 永年摂動の検証**: 昇交点赤経の後退率の解析値との突合（pointmass-j2 の
   軌道スケール検証）
4. **GMST エポック対応**: ECI 基準を打上時刻から J2000 等の標準エポックへ
5. **軌道要素出力**: a, e, i, Ω, ω, ν の出力列追加
6. **多段分離の E2E テスト**: 分離時の状態連続性・質量収支の自動検証
   （現状は単段シナリオのみ）
7. **大迎角空力**: sin(α) 形式の法線力オプション、Cd(Mach, α) の 2 変数テーブル
